# Breadth-First Search (BFS) in Java

## 📖 Overview
This project demonstrates the **Breadth-First Search (BFS)** algorithm implemented in Java.  
BFS is a graph traversal technique that explores nodes level by level using a queue.  
It is widely used in shortest path problems, cycle detection, and level-order traversal in trees.

## ⚙️ Features
- Graph representation using adjacency lists
- BFS traversal starting from a given source node
- Example graph with edges and traversal output

## 🛠️ Requirements
- Java Development Kit (JDK) 8 or higher
- Any Java IDE (e.g., IntelliJ IDEA, Eclipse, NetBeans) or command-line tools
